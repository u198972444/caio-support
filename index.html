AI隨身聽 技術支援

有任何問題？先看看常見問題，或直接聯繫我們。

Q：如何訂閱 Premium？
A：打開 App → 點擊底部「我的」→ 點擊「升級 Premium」→ 選擇月度、年度或終身買斷方案 → 透過 Apple ID 付款完成訂閱。
Q：如何取消自動續訂？
A：打開 iPhone 的「設定」→ 點擊你的 Apple ID → 「訂閱項目」→ 找到 AI隨身聽 → 點擊「取消訂閱」。取消後仍可使用至當前訂閱週期結束。
Q：播放沒有聲音怎麼辦？
A：請檢查：1) 手機是否開啟靜音模式；2) 音量是否調高；3) 關閉 App 後重新開啟；4) 確認網路連線正常。
Q：課程可以離線收聽嗎？
A：目前版本需要連網播放。離線下載功能將在未來版本中推出。
Q：更換手機後訂閱還在嗎？
A：只要使用同一個 Apple ID 登入，訂閱狀態會自動恢復。終身買斷方案同樣綁定 Apple ID，更換設備不影響使用。
Q：可以免費試聽嗎？
A：可以！S1（AI技術築基）和 S2（Agent架構）共 62 課全部免費開放，不需要訂閱即可收聽。
